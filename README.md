# 🚛 Sandhu Motors – Heavy Vehicle Service & Garage Website

A modern, responsive website developed for **Sandhu Motors**, a heavy vehicle diagnostics and repair garage in Nanded. The website showcases services, fleet maintenance solutions, customer reviews, gallery, and online booking while providing a smooth user experience across all devices.

## 🌐 Live Demo

https://sandhu-motors.vercel.app

## ✨ Features

- Responsive and mobile-friendly design
- Modern UI with Next.js and Tailwind CSS
- Multi-page website
- Service Booking Form
- Fleet Maintenance Information
- Diagnostics & Repair Services
- Customer Reviews
- Image Gallery
- Contact & Location Section
- SEO Optimized (Sitemap, Robots.txt, Metadata)
- Fast deployment using Vercel

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- HTML5
- CSS3
- Git & GitHub
- Vercel

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/anupreet04/sandhu-motors.git
```

### Navigate to project

```bash
cd sandhu-motors
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
